# PHP Practice Programs

A simple PHP learning repository containing beginner-level programs and exercises created while practicing core PHP concepts and problem-solving techniques.

This repository includes small standalone programs for mathematical logic, date handling, and basic algorithm implementation.


## Topics Covered

- PHP fundamentals
- Mathematical problem solving
- Date handling in PHP
- Function implementation
- Basic algorithmic logic


## Files Included

### `date.php`

Demonstrates date and time handling concepts using PHP.

### `fibonacci.php`

Implements Fibonacci sequence generation using PHP logic and loops.


## Technologies Used

- PHP
- HTML
- Basic Web Programming

## Running the Programs

### Using Local PHP Server

Run the following command:

```bash
php -S localhost:8000
```

Then open:

```text
http://localhost:8000
```

in your browser.
